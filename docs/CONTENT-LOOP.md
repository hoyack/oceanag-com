# Continuous content loop

## Cadence and owner
Hoyack portfolio content owner publishes one field dispatch every two weeks and reviews evergreen pages monthly.

## Sources
Operator interviews with consent, USDA/NASS/extension sources, equipment and workflow documentation, peer-reviewed research when a factual claim requires it, and original process analysis.

## Template
Question → operating context → observed signal → decision boundary → practical pattern → uncertainty → sources/review date → CTA.

## Approval
Draft owner → factual/source review → CMO editorial review for claims/voice → publish → 30-day correction check. Sponsorship requires disclosure review before publication.

## Freshness metrics
Percent of factual notes with source and review date; notes reviewed on schedule; open corrections; days since last dispatch; subscriber and qualified-conversation trend.
